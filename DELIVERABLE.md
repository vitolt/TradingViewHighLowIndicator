## 📋 Описание

**HighLow.pine** — основной выходной файл проекта High-Low Levels Indicator для TradingView.

Это готовый к использованию индикатор на Pine Script v5, который отображает на графике горизонтальные уровни максимумов и минимумов дневных, недельных и месячных периодов.

## 🎯 Функциональность

### Поддерживаемые уровни (6 типов)

1. **Daily High (DH)** — максимум дня
2. **Daily Low (DL)** — минимум дня
3. **Weekly High (WH)** — максимум недели
4. **Weekly Low (WL)** — минимум недели
5. **Monthly High (MH)** — максимум месяца
6. **Monthly Low (ML)** — минимум месяца

### Основные возможности

✅ Отображение 6 типов уровней на графике  
✅ Логика пересечения: линия заканчивается в точке пересечения  
✅ Прозрачность для пересечённых уровней (0-100%)  
✅ Фильтр по тайм-фреймам:
- На 1W: только WH, WL, MH, ML
- На 1M: только MH, ML
- На 1m-4h: все 6 типов

✅ Полная настройка параметров:
- Для каждого типа: цвет, ширина, стиль линии
- Глобальные: прозрачность, видимость, размер подписей
- Глубина просмотра (lookback_depth): 1-500 периодов

✅ Кэширование данных через request.security()  
✅ Динамическое удаление старых уровней

## 🔧 Исправления в v1.0.5

### ✅ Критическая ошибка 1: `var` в определении типа Level

**Было** (строки 79-80):
```pine
type Level
    ...
    var line ln      // ❌ Ошибка: var не может быть в типе
    var label lb
```

**Исправлено**:
```pine
type Level
    ...
    line ln          // ✅ Правильно: просто line
    label lb         // ✅ Правильно: просто label
```

**Причина ошибки**: В Pine Script v5 ключевое слово `var` не может использоваться внутри определения типа (type declaration). `var` используется только для глобальных переменных и переменных внутри функций для сохранения состояния между барами.

---

### ✅ Критическая ошибка 2: Отсутствующие параметры в Level.new()

**Было** (4 вызова):
```pine
// Строка 174 (Daily Low)
new_lv = Level.new(dl_val, "DL", bar_index, 0, false, "D")  // ❌ Не хватает параметров

// Строка 207 (Weekly Low)
new_lv = Level.new(wl_val, "WL", bar_index, 0, false, "W")

// Строка 224 (Monthly High)
new_lv = Level.new(mh_val, "MH", bar_index, 0, true, "M")

// Строка 240 (Monthly Low)
new_lv = Level.new(ml_val, "ML", bar_index, 0, false, "M")
```

**Исправлено**:
```pine
// Все 4 вызова теперь включают dummy_line, dummy_label
new_lv = Level.new(dl_val, "DL", bar_index, 0, false, "D", dummy_line, dummy_label)
new_lv = Level.new(wl_val, "WL", bar_index, 0, false, "W", dummy_line, dummy_label)
new_lv = Level.new(mh_val, "MH", bar_index, 0, true, "M", dummy_line, dummy_label)
new_lv = Level.new(ml_val, "ML", bar_index, 0, false, "M", dummy_line, dummy_label)
```

**Причина ошибки**: Конструктор Level.new() требует 8 аргументов, но 2 вызова передавали только 6. Недостающие параметры — это поля `ln` (line) и `lb` (label), которые инициализируются через глобальные переменные `dummy_line` и `dummy_label`.

## 🚀 Как использовать

### 1. Загрузка в TradingView

1. Открыть TradingView
2. Перейти в Pine Script Editor
3. Создать новый скрипт
4. Скопировать содержимое HighLow.pine (v1.0.5)
5. Нажать "Add to Chart"

### 2. Настройка параметров

После добавления на график открыть настройки индикатора и отрегулировать:
- Lookback Depth (по умолчанию 10)
- Цвета для каждого типа уровня
- Ширину и стиль линий
- Прозрачность пересечённых уровней
