# High-Low Levels Indicator для TradingView

Индикатор отображает на графике TradingView горизонтальные уровни, обозначающие максимумы и минимумы дневных, недельных и месячных периодов. Уровни автоматически заканчиваются при пересечении ценой и переходят в режим "ослабленной" видимости.

**Версия**: 1.0  
**Статус**: Код завершён, готов к тестированию в TradingView

## 🎯 Основная функциональность

✅ **Отображение 6 типов уровней**
- Daily High (DH) / Daily Low (DL)
- Weekly High (WH) / Weekly Low (WL)
- Monthly High (MH) / Monthly Low (ML)

✅ **Логика пересечения**
- Линия заканчивается ровно в точке пересечения
- Пересечённые уровни отображаются полупрозрачно ("ослабленный" режим)

✅ **Объединение совпадающих уровней**
- Если максимум дня = максимум недели → одна линия с подписью `DH+WH`

✅ **Фильтр по тайм-фреймам**
- На интрадей (1m–4h): все 6 уровней
- На дневном (1D): все 6 уровней
- На недельном (1W): только WH, WL, MH, ML
- На месячном (1M+): только MH, ML

✅ **Кэширование данных**
- Экстремумы старших ТФ получаются через `request.security()`
- Обновление только при переходе на новый период, без перерисовки

✅ **Полностью настраиваемые параметры**
- Для каждого уровня: цвет, ширина, стиль, подпись
- Глубина просмотра (1–500 периодов)
- Прозрачность пересечённых уровней

## 📝 Открытый вопрос

**`lookback_depth` — что именно должна означать эта глубина?**

Текущая реализация: держит на графике `lookback_depth * 2` последних уровней каждого типа.

Альтернатива: создавать уровни только за последние `lookback_depth` периодов, прежние не рисовать.

**Результат**: на старой истории уровни двухлетней давности либо видны, либо нет.

Уточнение требуется при первом запуске на графике — см. VERIFICATION.md.

## 🔧 Архитектура (вкратце)

Индикатор использует:
- **Тип `Level`** для хранения информации о каждом уровне (цена, подпись, линия, лейбл, статус пересечения)
- **`request.security`** для получения закрытых экстремумов старших ТФ (без перерисовки)
- **`ta.change(time(...))`** для определения границ периодов
- **Массив `levels`** для хранения всех активных и пересечённых уровней
- **Функции-утилиты** для определения стилей, цветов, видимости

Полная архитектура см. в **[SDD.md](SDD.md)**
