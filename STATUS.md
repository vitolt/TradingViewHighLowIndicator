#### Исправленные проблемы:
- ❌ **Была**: Проверка пересечения через `close` → ✅ **Теперь**: Правильно через `high`/`low`
- ❌ **Была**: Нет фильтра тайм-фреймов → ✅ **Теперь**: Функция `f_is_timeframe_qualified()`
- ❌ **Была**: Линии не заканчиваются при пересечении → ✅ **Теперь**: `line_x2` зависит от `cross_bar`
- ❌ **Была**: Неправильная логика создания уровней → ✅ **Теперь**: Переписана логика добавления/обновления
- ❌ **Была**: Отсутствовала прозрачность пересечённых → ✅ **Теперь**: `f_get_display_color()` с параметром
- ❌ **Была**: Нет поддержки глубины просмотра → ✅ **Теперь**: Очистка старых уровней реализована

#### Новая архитектура (HighLow.pine):
- **Версия**: Pine Script v5 (361 строка)
- **Структура**: Type `Level` с полями price, label_tags, start_bar, cross_bar, is_high, level_type, ln, lb
- **Логика уровней**: Правильная проверка high > price и low < price для определения пересечения
- **Фильтр ТФ**: На 1W показываются только WH/WL/MH/ML; на 1M только MH/ML
- **Прозрачность**: Пересечённые уровни автоматически получают указанную прозрачность
- **Кэширование**: Данные старших ТФ получаются через `request.security()` на каждом баре
- **Параметры**: Полная настройка цвета, ширины, стиля для каждого типа уровня

## 🔍 Открытые вопросы

### 1. Объединение совпадающих уровней
**Статус**: ❓ Не реализовано в текущей версии

Требование из REQUIREMENTS.md (п. 4.2):
> "Если экстремумы разных периодов совпадают по цене (напр., дневной макс = недельный макс) - они объединяются в один уровень с комбинированным лейблом (напр., "HW+HD")"

**Текущее поведение**: Создаёт отдельные линии для каждого типа уровня, даже если цена совпадает.

**Решение**: Может быть реализовано в версии 1.1 после тестирования текущей версии.

### 2. Интерпретация lookback_depth
**Статус**: ⏳ Требуется уточнение при тестировании

Текущая реализация: удаляет уровни старше `lookback_depth * 50` баров.

**Варианты интерпретации**:
- **А (текущее)**: Уровни по количеству баров (lookback_depth = 10 → удалять уровни > 500 баров)
- **Б (альтернатива)**: Уровни по глубине периодов (lookback_depth = 10 дней на дневном графике)

**Требуется уточнение**: Какой подход более интуитивен для пользователя?

## 💡 Ключевые особенности новой версии

| Функция | Реализация |
|---------|-----------|
| **Логика пересечения** | Проверка `high > price` для highs, `low < price` для lows |
| **Остановка линии** | Линия продолжается до `cross_bar`, после которого заканчивается |
| **Фильтр ТФ** | `f_is_timeframe_qualified()` скрывает младшие ТФ на старших графиках |
| **Прозрачность** | `f_get_display_color()` применяет прозрачность к пересечённым уровням |
| **Данные старших ТФ** | `request.security()` получает high/low с D, W, M ТФ |
| **Очистка** | Уровни удаляются при превышении `lookback_depth * 50` баров |
| **Параметры** | Полная настройка цвета, ширины, стиля для DH/DL/WH/WL/MH/ML |
