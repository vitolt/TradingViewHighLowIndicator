# Требования к индикатору High-Low Levels для TradingView

**Версия**: 1.0  
**Дата обновления**: 2026-10-07 18:35  
**Статус реализации**: ✅ Код переписан и готов к тестированию

## 1. Описание

Индикатор отображает на графике горизонтальные линии, отмечающие:
- Максимум недели (Weekly High)
- Минимум недели (Weekly Low)
- Максимум дня (Daily High)
- Минимум дня (Daily Low)
- Максимум месяца (Monthly High)
- Минимум месяца (Monthly Low)

## 2. Основная логика отображения

### 2.1 Видимость линий
- Линия отображается только если цена её ещё не пересекала в более поздние периоды
- Когда цена пересекает уровень (max/min), линия **заканчивается** в точке пересечения
- Линия не продолжается ниже/выше этой точки после пересечения

### 2.2 Временные периоды для расчёта
- Индикатор анализирует **только завершённые периоды**
- Текущий незавершённый период (текущая свеча) не учитывается в расчётах
- По умолчанию глубина просмотра: **10 периодов назад**

### 2.3 Поддержка тайм-фреймов

#### 2.3.1 Источник данных для уровней
- Уровни каждого типа рассчитываются **по данным своего тайм-фрейма**, а не по данным текущего графика
- Месячные экстремумы берутся с месячного ТФ, недельные — с недельного, дневные — с дневного
- Значения **кэшируются** и пересчитываются только при переходе на новый период соответствующего ТФ
  (например, месячный экстремум пересчитывается только при начале нового месяца)

#### 2.3.2 Фильтр по текущему тайм-фрейму
- Отображаются **только уровни периодов, которые больше или равны текущему тайм-фрейму графика**
- Уровни младших периодов не рассчитываются и не отображаются

| Текущий ТФ графика | Daily | Weekly | Monthly |
|--------------------|-------|--------|---------|
| 1m … 4h (интрадей) | ✅ | ✅ | ✅ |
| 1D (день)          | ✅ | ✅ | ✅ |
| 1W (неделя)        | ❌ | ✅ | ✅ |
| 1M (месяц)         | ❌ | ❌ | ✅ |

- Настройки отключённых по этому правилу уровней остаются доступными, но не влияют на отображение

#### 2.3.3 Отрисовка при нехватке истории
- Если бар начала периода находится за пределами доступной истории графика
  (например, месячный экстремум на минутном графике), уровень всё равно отображается
- Линия рисуется **от первого доступного бара** графика, так как само значение уровня известно из данных старшего ТФ

## 3. Параметры настройки

### 3.1 Глубина анализа
- Параметр: "Lookback Depth" (количество периодов)
- Тип: целое число
- По умолчанию: 10
- Диапазон: 1-500

### 3.2 Визуализация каждого типа уровня
Для каждого типа (Daily High, Daily Low, Weekly High, Weekly Low, Monthly High, Monthly Low):
- **Включение/выключение**: чекбокс для видимости уровня
- **Цвет линии**: выбор цвета
- **Ширина линии**: (1-5)
- **Стиль линии**: сплошная, пунктир, точки
- **Надпись/Лейбл**: текст, отображаемый рядом с линией (e.g., "DH", "WL", "MH")
- **Дата экстремума**: автоматически добавляется в лейбл в формате "MMM DD" (e.g., "DH (Oct 07)")

### 3.3 Глобальные параметры
- **Прозрачность (Transparency)**: 0-100% для пересечённых уровней
- **Показывать пересечённые уровни**: вкл/выкл — если отключено, пересечённые уровни скрываются
- **Показывать подписи**: включать/отключать отображение лейблов
- **Добавлять цену в подпись**: опция добавления цены к лейблу (e.g., "DH 1.2345")
- **Размер подписи**: tiny / small / normal

## 4. Расчёты и логика

### 4.1 Определение пересечения
**Для Daily High / Weekly High / Monthly High (уровни максимумов)**:
- Пересечение происходит, когда `high` свечи > цены уровня
- Линия **заканчивается ровно в баре, где произошло пересечение**
- После пересечения уровень отображается с указанной прозрачностью

**Для Daily Low / Weekly Low / Monthly Low (уровни минимумов)**:
- Пересечение происходит, когда `low` свечи < цены уровня
- Линия **заканчивается ровно в баре, где произошло пересечение**
- После пересечения уровень отображается с указанной прозрачностью

### 4.2 Определение периодов
- **Daily**: с 00:00 до 23:59 (по часовому поясу графика TradingView)
- **Weekly**: неделя (по часовому поясу графика TradingView)
- **Monthly**: месяц (1-е число - последнее число, по часовому поясу графика TradingView)
- **Часовой пояс**: Автоматически используется часовой пояс, установленный на графике в TradingView (без дополнительного параметра выбора в индикаторе)

### 4.3 Поиск экстремумов
- Для каждого завершённого периода ищется максимум и минимум
- Если в одном периоде несколько одинаковых экстремумов - они отображаются как **один уровень**
- Если экстремумы разных периодов совпадают по цене (напр., дневной макс = недельный макс) - они **объединяются в один уровень** с комбинированным лейблом (напр., "DH+WH")
- Лейбл уровня показывает типы периодов, к которым относится данный максимум/минимум
- Проверяется, был ли уровень пересечен в последующих периодах
- Если пересечен (цена прошла выше максимума или ниже минимума по high/low свечи) - линия **заканчивается** в точке пересечения и отображается с **меньшей прозрачностью** (блёклая)
- Если не пересечен - линия отображается до конца видимой области графика с полной прозрачностью

## 5. Требования к интерфейсу

### 5.1 Название индикатора
- На английском: "High-Low Levels"
- На русском: "Уровни High-Low"

### 5.2 Внешний вид
- Линии должны быть чётко видны, но не отвлекающе
- Лейблы должны быть читаемыми и не перекрывать ценовые данные
- Поддержка светлой и тёмной тем TradingView

### 5.3 Документация
- Краткая инструкция по использованию индикатора
- Описание параметров настройки

## 6. Поддерживаемые инструменты

Индикатор разработан для работы на **любых графиках в TradingView**, включая:
- Акции (NYSE, NASDAQ и другие биржи)
- Криптовалюты (24/7)
- Фьючерсы (с учётом особенностей торговых сессий)
- Валютные пары (Forex)
- Любые другие инструменты, доступные на платформе TradingView

## 7. Ограничения и особенности

- Индикатор работает на основе закрытых периодов (завершённых свеч)
- Максимальная глубина просмотра может быть ограничена ресурсами TradingView
- Линии, пересечённые ценой, остаются видны вплоть до точки пересечения для контекста
- Разные инструменты и тайм-фреймы используют одну и ту же логику определения периодов
- При необходимости пользователь может переключать часовой пояс для разных торговых сессий
- Максимум 500 линий и 500 лейблов одновременно (ограничение TradingView)
